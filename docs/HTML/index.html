The shape, in one paragraph

SoraMech is three independent programs sharing a map directory on disk: a thin HTTP file CRUD server that the browser editor talks to, a runner that walks the map and executes it, and the editor itself. The editor never runs maps. The runner never speaks to the editor. The map directory is the only contract. Phase 2's runner is a synchronous Lua interpreter; phase 3 replaces it with a C thread pool runner that owns its own pool, opens language-spec .so files at startup, and routes values through per-input-port ring buffers. Box JSON is unchanged across the cutover.
