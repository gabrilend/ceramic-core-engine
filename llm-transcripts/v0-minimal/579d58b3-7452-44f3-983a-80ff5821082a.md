// Lua spec, sketch
int lua_invoke(handle, file_path, fn_name,
               input_data[], input_sizes[], n_inputs,
               out_buf, out_buf_capacity, out_size) {
    lua_State *L = handle;
    luaL_loadfile(L, file_path);
    lua_getfield(L, -1, fn_name);

    for (int i = 0; i < n_inputs; i++) {
        // each input is a JSON value as bytes; parse into a Lua value
        cjson_decode_to_lua(L, input_data[i], input_sizes[i]);
    }

    lua_pcall(L, n_inputs, 1, 0);

    // serialize return value back to JSON bytes
    *out_size = cjson_encode_from_lua(L, -1, out_buf, out_buf_capacity);
    return 0;
}

```
Iterator box (call type)
  Inputs:
    value    (from upstream, N-cell pop slot)
    counter  (self-loop, N-cell pop slot, primed with 0 at startup)
  Outputs (N branches)
    output_0, output_1, ... output_{N-1}
    next_counter (self-loop wire back to counter input)

Per invocation:
  pop value, pop counter
  route value to outputs[counter % N]
  push (counter + 1) to next_counter

```

```
Dispatch action for a router box:
  1. (optional) Invoke spec on inputs → returns value (and possibly a branch hint)
  2. Compute branch via routing_rule:
       - "comparand"        → compare(value, params.comparand) → lt/eq/gt
       - "counter"          → params.counter++ % N → output_K
       - "function_return"  → spec returned (value, branch); use branch
       - "fan_all"          → no branch, fire all (= plain call)
  3. Push value (or popped input, for counter-mode without spec) to selected branch(es)

```
